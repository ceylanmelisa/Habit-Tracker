# Habit Tracker Application

## Description
This is a standalone command-line interface (CLI) application created in Python to help users track their daily habits. The project demonstrates various core Python elements, including Object-Oriented Programming (Classes/Modules), File Handling (JSON serialization with Context Managers), Custom Exceptions, Regex, Decorators, Lambda functions, Generators, and Comprehensions.

## Run Instructions
1. Ensure Python 3 is installed on your computer.
2. Open your terminal or command prompt.
3. Navigate to the folder containing the project files.
4. Run the main application by executing the following command:
   ```bash
python main.py
```
5. Follow the interactive menu on the screen to add new habits or list existing ones.
